# 문서 탐색과 검색 검증

2026-11-05에 Playwright Chromium으로 통합 정적 빌드의 영어·한국어 Typography 상세 페이지를 확인했다. 데스크톱은 1440 × 900, 모바일은 375 × 800에서 확인했으며 모션 감소 설정을 사용했다. 브라우저 콘솔과 페이지 오류는 없었다.

| 검증 | 결과 |
| --- | --- |
| 데스크톱 사이드바 | 언어별 컴포넌트 링크 66개와 올바른 `aria-current="page"`를 확인했다. 현재 Typography 링크가 스크롤 영역 안에 표시됐다. 시작하기 그룹은 처음에 접혀 있었으며 버튼으로 펼칠 수 있었다. |
| Pagefind 검색 | 영어 `runtime`의 첫 결과 묶음에서 페이지·섹션 링크 31개, 한국어 `런타임`에서 18개를 확인했다. 모든 링크가 해당 언어 경로로 연결됐고 검색어 강조를 확인했다. 더 보기 버튼이 표시되면 활성화 후 링크 수가 늘어나는지 확인했다. 검색어를 빠르게 바꿔 일치하지 않는 입력을 남겼을 때 결과 없음 메시지와 링크 0개를 확인했다. |
| 검색 키보드 조작 | 영어에서 Ctrl+K, 한국어에서 Cmd+K로 Dialog를 열었다. 검색 입력에 포커스가 갔고 Escape로 닫았을 때 이전에 선택한 사이드바 그룹 버튼으로 포커스가 돌아왔다. |
| 모바일 Sheet | 언어별 링크 66개를 확인했다. 현재 Typography 링크가 스크롤 영역 안에 표시됐다. Shift+Tab 이후 포커스가 Sheet 안에 유지됐고 Escape로 닫은 뒤 메뉴 버튼으로 돌아왔다. |
| 개발 서버 | 양 언어에서 색인을 사용할 수 없다는 안내와 입력 비활성화를 확인했다. Dialog를 열면 닫기 버튼에 포커스가 갔고 Escape로 닫으면 검색 버튼으로 돌아왔다. |

`npm run typecheck --workspace @viewstem/docs`는 90개 파일에서 오류, 경고, 힌트 없이 통과했다. 브라우저 검증은 터미널에서 일회성 스크립트로 실행했다. 검색 응답 순서를 네트워크 지연으로 역전시키는 시험은 포함하지 않았다. 정적 빌드 검증은 공통 CSS 레이어 순서를 조정하기 전에 실행했다.
