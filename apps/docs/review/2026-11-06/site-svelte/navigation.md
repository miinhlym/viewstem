# 문서 탐색과 검색 검증

2026-11-06에 Playwright Chromium 151.0.7922.34로 4323 포트에서 제공한 정적 빌드의 영어·한국어 Typography 페이지를 확인했다. 데스크톱 1440 × 900과 터치 모바일 375 × 800에서 모션 감소 설정을 사용했다. 네 조합 모두 브라우저 콘솔 및 페이지 오류가 0건이었다.

| 검증 | 결과 |
| --- | --- |
| 데스크톱 사이드바 | 언어별 컴포넌트 링크 66개와 `aria-current="page"`를 확인했다. 현재 Typography 링크가 스크롤 영역 안에 표시됐다. 접혀 있던 시작하기 그룹을 열었을 때 `aria-expanded`가 바뀌고 `aria-controls`로 연결한 영역이 표시됐다. |
| Pagefind 검색 | 영어 `runtime`은 첫 묶음에서 페이지·섹션 링크 31개, 한국어 `런타임`은 18개를 표시했다. 더 보기 후 각각 55개, 26개로 늘었다. 결과가 모두 현재 언어에 속했고 검색어 강조가 표시됐다. 섹션 링크를 선택한 뒤 목적지에 해당 해시의 제목이 있음을 확인했다. |
| 검색 입력과 키보드 | 영어 Ctrl+K와 한국어 Cmd+K가 검색 입력에 포커스를 보냈다. 입력을 연속 변경해 `nonsense qyzzuvx zkzzxvy`로 끝냈을 때 결과 없음과 링크 0개를 확인했다. Escape로 닫으면 이전 사이드바 버튼으로 포커스가 돌아왔고, 다시 열었을 때 입력이 비어 있었다. |
| 모바일 문서 메뉴 | 언어별 컴포넌트 링크 66개와 현재 Typography 링크의 가시성을 확인했다. Shift+Tab 후 포커스가 Sheet 안에 있었고, Escape로 닫은 뒤 문서 메뉴 버튼으로 돌아왔다. |
| 모바일 목차 | ArrowDown으로 목차를 열었을 때 항목 5개가 표시됐다. 미리보기 항목을 Enter로 선택했을 때 메뉴가 닫히고 `#component-preview`로 이동했다. |

`node apps/docs/scripts/verify-sidebar-scroll.mjs`의 10개 검증도 통과했다. 한영 × 밝음·어둠 × 1024·1440px의 8조합에서 사이드바 하이드레이션을 350ms 지연했다. 사전에 열린 그룹이 지연 중에도 표시됐고, 첫 표시부터 하이드레이션 이후까지 관찰한 49~125개 프레임의 `scrollTop`은 각 조합에서 1936px였다. 새로고침·뒤로 가기와 다른 섹션으로 이동할 때 그룹 상태를 확인했다. 세션 저장소를 차단해도 현재 링크가 보였으며 모바일 메뉴는 저장된 데스크톱 스크롤 값을 유지했다.
