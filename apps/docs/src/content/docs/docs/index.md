Viewstem is a framework-independent declarative UI runtime. Describe screens, state, queries, and actions in JSON and connect them to components in your app.

## Run your first view

Try the [first View](../examples/first-view/) directly in your browser. To run it in a Svelte app, follow [Installation](./installation/) and then [Quick Start](./quickstart/).

<a id="core-concepts"></a>

## Learn the core concepts

Start with [View and Component](./concepts/view-and-component/), then follow the sidebar through values and inputs, State, derived values, events and Actions, and data queries. Finish with conditions and lists, reusable Components, and resources and types. Each page explains a concept with JSON and its expected result; use the previous and next links to read in order.

<a id="task-guides"></a>

## Put the concepts together

The [form validation](./guides/form-validation/) and [query dashboard](./guides/query-dashboard/) guides combine multiple features. Check the [DSL and API reference](./reference/) for syntax and package APIs.

## Package guides and APIs

Use [Core](./core/) for runtime, State, and data APIs, [Viewstem UI](./ui/) to render the shared UI catalog in a browser DOM container, and [Svelte](./svelte/) and [Svelte UI](./svelte-ui/) to work with native Svelte components. Look up exact JSON fields in the [DSL reference](./dsl/).
