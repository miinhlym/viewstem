[Core](../../core/)는 View와 State를 소유합니다. [DOM](../../dom/) 또는 [Svelte](../../svelte/) 렌더러는 View를 화면에 연결합니다. View 하나에 표시 연결을 여러 개 둘 수 있고 렌더링 결과는 연결마다 따로 확인합니다.

## 마운트와 표시 연결

`mount()`는 마운트가 소유하는 View를 만듭니다. `attach(view, target)`는 기존 View를 빌려 표시합니다. 소유 View를 언마운트하면 해당 View의 수명이 끝나고 대기 중인 작업이 취소됩니다. 빌린 View에서 표시 연결을 해제하면 호스트가 View 소유권을 유지합니다. 앱이 닫힐 때 렌더러와 앱이 소유한 Runtime을 정리합니다.

## 필요한 완료 신호 기다리기

| 신호 | 확인하는 범위 |
| --- | --- |
| `mounted.ready` | View 준비와 표시 연결이 끝났습니다. |
| `mounted.whenRendered()` | 해당 표시 연결의 DOM 반영 완료 또는 실패입니다. Query 실행이나 브라우저 화면 그리기는 별도로 진행됩니다. |
| `view.initial` | 실행 자격이 있는 초기 Query의 결과입니다. 보고된 Query 오류를 확인하세요. |

표시에 실패하면 해당 연결의 오류를 확인하세요. 한 연결의 실패 이후에도 View와 다른 표시 연결은 사용할 수 있습니다. 부모 슬롯을 교체하면 자식 DOM 인스턴스가 다시 만들어질 수 있습니다. View 노드의 수명이 유지되면 Core State는 보존됩니다.

## 호스트 기능 제공하기

필요한 기능을 사용하는 Action을 실행하기 전에 호스트에서 그 기능을 제공합니다. 필수 호스트 기능이 없으면 Action은 첫 단계가 실행되기 전에 실패합니다. 비밀 참조나 Login을 사용하는 요청은 [HTTP 실행기](../../core/http/)로 서버 측 비밀 해석과 목적지 권한 검사를 제공합니다.
