Viewstem은 프레임워크에 독립적인 선언형 UI 런타임입니다. JSON으로 화면, 상태, 쿼리, 액션을 정의하고 앱의 컴포넌트에 연결합니다.

## 첫 화면 실행하기

[첫 View 예제](../examples/first-view/)는 브라우저에서 바로 실행할 수 있습니다. Svelte 앱에서 실행하려면 [설치](./installation/)를 마친 뒤 [빠른 시작](./quickstart/)을 따라가세요.

<a id="core-concepts"></a>

## 핵심 개념 살펴보기

[View와 Component](./concepts/view-and-component/)부터 시작해 값과 입력, State, 계산된 값, 이벤트와 Action, 데이터 조회 순으로 읽으세요. 이어서 조건과 목록, Component 재사용, 리소스와 타입을 다룹니다. 각 페이지는 JSON과 예상 결과로 개념을 설명하며, 하단의 이전·다음 링크로 순서대로 이동할 수 있습니다.

<a id="task-guides"></a>

## 만들면서 익히기

[폼 입력 검증](./guides/form-validation/)과 [조회 대시보드](./guides/query-dashboard/)는 여러 기능을 함께 사용하는 예제를 보여줍니다. 문법과 패키지 API는 [DSL·API 레퍼런스](./reference/)에서 확인할 수 있습니다.

## 패키지별 사용법과 API

[Core](./core/)에서 실행·상태·데이터 API를 확인하세요. 브라우저 DOM에서 공통 UI 카탈로그를 쓰려면 [Viewstem UI](./ui/)를, 네이티브 Svelte 컴포넌트를 쓰려면 [Svelte](./svelte/)에서 앱 컴포넌트 등록 방법을 확인하세요. JSON 정의의 정확한 필드는 [DSL 레퍼런스](./dsl/)에서 찾을 수 있습니다.
