## What this proposes

외부 소비 앱에서 Viewstem을 사용하는 에이전트를 위해, 공통 `viewstem` 스킬 하나와 작업별 참조 자료를 제공한다. Codex와 Claude Code를 동등하게 지원하되 설치·발견 등 호스트 차이만 별도 안내하며, 라이브러리와 스킬은 각각 설치한다. 큰 UI 지원 JSON은 선택 조회 도구로 필요한 계약만 읽도록 하고, 외부 소비 검증과 문서만 제공한 기준선과의 행동 비교를 통해 구성 요소의 필요성과 배포 가능 여부를 판단한다. 실제 스킬·도구 구현과 행동 평가는 아직 수행하지 않았다.

## How the existing system works, per this document

Viewstem 소비 앱은 core, Svelte 연결 계층, 제공 UI의 공개 API와 명시적인 등록·상태·수명 계약을 조합한다. 설치된 패키지의 공개 타입은 API 시그니처를, UI·CEL 지원 JSON은 지원 목록과 제약을 제공하며, 실행·수명·스타일 의미는 대응 문서에서 확인한다. 공개 snapshot과 오류 채널로 상태를 관찰할 수 있지만, Query 완료·core 상태 변경·렌더링 성공은 각각 구분해야 한다. 현재 확인된 근거는 기존 workspace에서의 읽기 전용 조사이며 독립 소비 설치나 제안 도구의 실행 증거는 아니다.
