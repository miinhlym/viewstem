# 사이트 뱃지·카드 디자인 간소화

2026-11-05. 사용자가 불필요한 뱃지와 카드를 줄이고 사이트 디자인을 개선하도록 요청했다. 현재 명세 §3.4와 D113에 기록했다.

## 범위와 판단

홈, 문서, 예제 목록·상세, Playground의 공통 탐색과 콘텐츠 표현을 확인했다. 기존 Pretendard·D2Coding, 청록색 강조, 콘텐츠 순서는 유지한다. 색상은 기존 흰색 `#ffffff`, 배경 `#f8fafc`, 본문 `#172437`, 보조 텍스트 `#4c5c70`, 강조 `#0f766e`를 재사용한다.

실행 가능한 코드와 결과를 홈의 중심으로 두고, 나머지 설명은 장식보다 내용의 관계를 표현한다. 실행 흐름은 순서가 있으므로 번호를 유지하지만 뱃지로 감싸지 않는다. 특징은 번호 없는 단락, 예제는 제목·설명·이동 링크의 행으로 표현한다. 모든 섹션을 같은 카드 격자로 만들지 않는다.

```text
홈: 제목·설명 → 시작하기 / 예제 링크 → 코드와 실행 결과
    → 1. Action  2. State  3. Query  4. View
    → 특징 단락 → Svelte 연동 → 예제 링크 목록
문서: 본문 → 구분선 → 이전 페이지                 다음 페이지
```

## 변경

- `HomePage.astro`: 제목 위 분류 뱃지, 결과 뱃지, 상태 뱃지, 단계 번호 뱃지를 제거했다. 고객 상태는 의미를 보존하는 텍스트로 표시한다. 특징·단계·예제의 Card 래퍼를 제거하고 제목·목록·문단을 사용한다. 순서와 목록 의미는 보조 기술에서도 유지한다.
- 홈의 주 CTA는 버튼으로 유지하고 보조 탐색과 footer는 텍스트 링크로 바꿨다. 예제 전체 행은 실제 링크여서 키보드와 포인터로 이동할 수 있다. 필터는 실제 버튼과 `aria-pressed`를 유지하며 밑줄로 선택 상태를 표시한다.
- `home.css`: 열린 단락과 간격으로 위계를 정리했다. 모바일에서 흐름과 예제는 단일 열로 읽힌다. 실행 예제의 얇은 테두리와 코드 배경은 작업 영역을 구분하므로 유지한다.
- `docs/Pagination.astro`, `docs.css`: 이전·다음 카드 두 개를 구분선 아래 방향별 링크로 교체했다. 이전/다음 중 하나만 존재해도 해당 방향을 유지한다. 키보드 초점과 hover 표시를 제공한다.
- `header.css`, `docs.css`, `examples.css`: 공통 메뉴의 현재 위치는 밑줄, 문서·예제 사이드바는 세로선과 글자 강조로 표시한다. `aria-current`는 유지한다.
- 예제 목록·상세와 Playground는 이미 작업 패널과 구분선 중심이어서 불필요한 레이아웃 변경을 추가하지 않았다. 사용법을 보여 주는 실제 Card·Badge와 팝오버·검색창의 기능적 경계를 유지한다. 패키지 컴포넌트 자체의 스타일을 변경하지 않는다.

## 검증

- `apps/docs`에서 최종 `astro build` 통과: 119페이지와 Pagefind 검색 색인 생성. 기존 markdown deprecation·큰 번들·site 미설정 sitemap 경고는 남아 있다.
- [검증 기록](docs-design-simplification-verification-2026-11-05.json): 영·한 홈, 예제 목록, 첫 View 예제, Playground, 값과 입력 문서의 10개 경로 × 320·768·1440px, 총 30개 조합에서 가로 넘침·헤더 겹침·문서 하단 탐색 넘침 0개. 최종 정적 빌드를 앱 내 브라우저에서 확인했다.
- 홈의 Card 래퍼 11개와 Badge 9개를 제거했다. 실행 영역은 기능적 경계가 있는 일반 컨테이너로 유지한다. 별도 슬롯 예제는 실제 Card 1개와 Badge 2개가 여전히 렌더링된다.
- 홈 필터에서 전체 고객은 3명과 `filter = "all"`, 활성 고객은 2명과 `filter = "active"`로 바뀌며 `aria-pressed`도 동기화된다.
- 예제 행과 문서 이전·다음 링크의 Tab 초점 표시를 확인했고 Enter로 실제 목적지에 이동했다. 이전 페이지가 없는 개요 페이지의 다음 링크는 오른쪽 열에 유지된다.
- 모바일 문서 메뉴의 열림·닫힘과 `aria-expanded`, 선택된 사이드바 항목의 표시, Escape 후 메뉴 버튼으로 초점 복귀를 확인했다.
- 홈의 데스크톱·모바일 전후 화면과 문서 하단의 데스크톱·모바일 화면을 직접 검토했다. 홈·문서의 카드 반복을 덜어내고 콘텐츠 정렬, 제목 위계, 모바일 줄바꿈을 확인했다.
- 정적 `index.html` 122개의 내부 링크·앵커 참조 5,684개 검사에서 누락 0개. `git diff --check` 통과. 개발 서버의 한국어 홈도 HTTP 200으로 응답한다.
- 전후 화면은 Ego Chromium으로 확인했다. 후속 검사 중 Ego 실행 파일 연결이 사라져 앱 내 브라우저로 전환했고, 중단된 검사 시도는 위 완료 수치에 포함하지 않았다. Windows·Android 실기기 검증, 배포와 커밋은 수행하지 않았다.
