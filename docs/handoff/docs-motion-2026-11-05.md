# 읽기와 상태 이해를 돕는 사이트 모션

2026-11-05. 사용자가 과도한 장식 없이 요소별 애니메이션으로 가독성·이해·품질을 개선하도록 요청했다. 현재 명세 §3.4와 D114에 기록했다. 기존 서체, 색상, 카드 간소화, 페이지 구성은 유지한다.

## 적용 원칙과 범위

- 상태 변경과 조작은 즉시 수행하고, 모션은 변화가 일어난 위치와 탐색 방향을 보조한다. 애니메이션 완료를 기다려 값을 갱신하거나 탐색하지 않는다.
- `styles/motion.css`는 140ms 색상 전환과 200ms 패널 열림, 링크 화살표의 3px 방향 이동을 소유한다. 헤더 등의 기존 `transition-all`을 색상 관련 속성으로 제한해 화면 너비 변경 때 글자 크기·여백이 보간되지 않게 했다.
- 홈의 소개, 실행 예제 패널, Svelte 연동 코드 패널 3곳에만 360ms/6px의 일회 진입을 적용한다. 모든 본문·섹션을 숨겼다가 나타내지 않는다. 해당 영역은 JS 실행 전과 JS 비활성화 상태에서도 보인다. 해시로 이동한 페이지나 이미 초점이 있는 영역은 진입 효과를 생략한다.
- 필터 변경 시 새로 보이는 고객 행은 240ms로 나타나고 건수·State 값이 짧게 강조된다. 화면에 보이는 Action → State → Query → View 제목은 90ms 간격으로 420ms 색상 강조를 받는다. 최대 흐름 강조 길이는 690ms이며, 실제 필터 상태·행·건수는 지연 없이 바뀐다. 화면 밖의 요소나 이미 선택된 필터는 모션을 실행하지 않는다.
- 문서 검색창·모바일 메뉴·예제 목록 팝오버는 열릴 때 짧게 나타난다. 닫기·Escape·초점 복귀는 지연하지 않는다. 문서 해시 목적지 제목은 900ms 배경 강조로 위치를 알려준다.
- 예제 코드 재실행으로 성공한 결과가 교체될 때 180ms 페이드, 예제·Playground 오류에 200ms 페이드, Playground 실행 상태에 480ms 색상 강조를 적용한다. 잘못된 예제 코드에서는 마지막 성공 결과를 유지하는 기존 동작을 보존한다.
- `lib/site-motion.ts`는 자체 Web Animations만 추적한다. 같은 요소의 연속 호출은 앞선 효과를 취소한다. 모션 감소 설정 변경·탭 숨김·페이지 이탈 시 취소하고 완료 후 인라인 스타일을 남기지 않는다. `prefers-reduced-motion: reduce`에서 CSS 효과와 JS 효과를 모두 생략한다. 프레임워크·애니메이션 라이브러리 의존성을 추가하지 않았다.

## 검증

[실행 기록](docs-motion-verification-2026-11-05.json)에 브라우저에서 관찰한 값·실제 애니메이션 타이밍·반응형 결과를 보존한다.

- 최종 `astro build` 통과: 119페이지와 Pagefind 색인 생성. 기존 markdown deprecation·큰 번들·site 미설정 sitemap 경고는 유지된다. 런타임 패키지 변경이 없어 기존 패키지 빌드 출력을 사용했다.
- `site-motion.ts`의 strict TypeScript DOM 검사와 `git diff --check` 통과.
- 영·한 홈과 문서, 한국어 첫 View 예제와 Playground의 6개 경로 × 390·1440px × 일반/모션 감소 설정, 총 24개 정적 빌드 조합에서 가로 넘침·헤더 겹침·숨겨진 진입 영역·종료 후 남은 애니메이션 0개.
- 홈 필터의 즉시 상태 갱신, 240/420ms 효과와 0/90/180/270ms 흐름 지연을 실제 `getAnimations()`로 확인했다. 빠른 6회 연속 클릭 후 마지막 값이 맞고 각 제목에 효과가 하나만 존재한다. 종료 후 실행 효과 0개, 검사 대상의 인라인 style 잔여 0개.
- 실행 도중 모션 감소 설정을 변경하면 media-query change 이벤트가 처리된 다음 프레임에 자체 효과 0개. 원시 기록의 `reducedDuringMotion`은 change 이벤트 전달 전 관찰값이며, `reducedAfterMediaEvent`가 이벤트 처리 후 결과다. 감소 설정에서도 필터·메뉴·검색 동작은 유지된다.
- 연동 코드 패널의 첫 viewport 진입에는 효과 1개, 다시 스크롤해 진입할 때는 0개. JS 비활성화와 일반 모션 설정에서도 콘텐츠 모두 표시. `#example` 직접 진입에는 등장 효과 0개.
- 모바일 메뉴의 200ms 열림, `aria-expanded`·본문 inert 동기화, Escape 후 초점 복귀를 확인했다. 검색·예제 팝오버의 열림 효과와 감소 설정에서의 생략을 확인했다. 실제 Pagefind `계산` 검색 결과도 확인했다.
- 문서 앵커의 대상은 H2이며 제목 강조가 적용된다. Tab으로 다음 링크에 초점을 옮기면 3px 방향 이동과 초점 외곽선이 표시된다.
- 예제 실행 결과의 180ms 페이드, 잘못된 JSON의 오류 표시와 마지막 성공 결과 유지, 초기화 복구를 실행했다. Playground에서도 잘못된 JSON 오류와 정상 Button View 실행 후 상태 강조를 확인했다. 브라우저 오류 로그는 없었다.
- 문서 HTML 38개의 내부 링크·앵커 참조 1,264개 검사에서 누락 0개.
- 검증 환경은 macOS 앱 내 브라우저다. 실제 화면 변화와 종료 상태를 확인했으며 Windows·Android 실기기 검증이나 성능 벤치마크를 수행한 것은 아니다. 배포·커밋은 수행하지 않았다.
