# 문서 이관 검증 기록

기준일: 2026-10-28. 이 기록은 **문서 묶음의 정합성 검사**이며, Viewstem 런타임 구현 또는 제품 QA 결과가 아니다.

**과거 이관 기록:** 아래 수량·검사 주장은 10/28 묶음의 기록이다. 10/29 의미 리뷰에서는 당시 원본 통합 요약에도 있던 누락을 발견했다. 따라서 원본과의 일치만으로 승인 의미의 완전성을 증명하지 않는다. 수정 후 현재 검사 결과와 한계는 [별도 복원·검증 기록](semantic-review-2026-10-29.md)에 남긴다.

## 출처와 수록 범위

- 기준 문서: [Viewstem 통합 설계 명세](https://chatgpt.com/space/page_7842bb8bff0c8191be6cd5831e7e375f)의 이관 시점 원문.
- 현재 계약은 `docs/VIEWSTEM-SPEC.md`와 `docs/spec/`에 주제별로 분리했다.
- 원본 근거 분류 E01–E42를 보존했고, 인용된 고유 대화 메시지 ID 108개는 모두 로컬 원문 보관함에 대응한다.
- 관련 대화 1,530개(사용자 632, 어시스턴트 898)를 날짜별 27개 파일로 보관한다. 기간은 2026-10-08~28 KST다.
- 상세 보관함은 원문 파일, 19개 주제별 변천 정리, 근거 색인, 최신/통합 직전 명세 스냅샷을 포함한 33개 Markdown으로 구성한다.

## 확인한 항목

- 현재 명세의 JSON 코드 블록 **25개**를 독립 JSON으로 파싱했다.
- 문서 간 상대 파일 링크와 원문 근거 앵커가 실제 대상을 가리키는지 검사했다.
- 현재 리소스 기반 요청/선택적 서버 중계, `/ports`, Action `output`/void, slots·Grid·수명, 과거 승인 의미 보존을 원본과 대조했다.
- 공개용으로 정리한 문서에서 무관한 개인정보·사내 운영 사건·실제 비공개 엔드포인트를 제거했는지 확인했다.
- 원문 보관함에서는 설계와 무관한 메시지를 제외하고, 일부 맥락의 생략을 명시했다. 최신 기준 문서 스냅샷은 원본 해시와 일치한다.

## 확인하지 않은 것과 한계

- JSON Schema 검증기, 실제 런타임, CEL 구현체, 렌더러, 통합 테스트는 구현·실행한 것으로 보고하지 않는다.
- 과거 대화의 JSON에는 당시의 부분 예시나 이후 기각된 문법이 있다. 이를 현재 문법으로 고쳐 원문을 변조하지 않았다.
- 원문 보관함은 관련 대화 발췌 모음이지 전체 방의 완전한 내보내기가 아니다. 초기 기간의 공백, 비가시/삭제 메시지, 첨부 본문, 다른 로컬 스레드 전체의 미수록 가능성은 보관함 README에 명시한다.
- 설명용 SDK 함수명과 실제 패키지 구현 상태를 동일하게 취급하지 않는다. 남은 구체화 사항은 [구현 인수인계](implementation-start.md)와 [인수 행렬](acceptance-matrix.md)에 남겼다.

설치 후에도 로컬 프로젝트에서 파일 목록·문서 내용·원문 폴더의 Git 제외 상태를 확인해야 한다. 문서 이관은 commit·push 또는 구현 시작을 자동으로 승인하는 절차가 아니다.
