# Set identity/additionalProperties 수정 전

독립 리뷰가 저장된 배열·날짜 객체 Set 원소 재입력의 identity 단절과 schema-valued additionalProperties 검증 누락을 재현한 시점의 자체 소스와 95개 fixture 결과를 보존한다. snapshot/results/node22.json과 node24.json은 당시 285/285였지만 추가 반례를 포함하지 않으며 현재 적합성 통과 증거로 재사용하지 않는다. 외부 의존성은 각 결과의 sourceSha256과 lockfile을 따른다. .dart_tool은 환경 생성물이므로 보존하지 않는다.
