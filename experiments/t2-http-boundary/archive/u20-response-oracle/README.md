# U20의 대체된 응답 검사 기대값

이 폴더는 2026-10-29 당시 소스와 결과를 그대로 보존한다. P21은 API가 반환한 합성 secret까지 Viewstem이 차단해야 한다는 기대값으로 실패했다.

2026-10-30 U21에서 사용자는 API 응답 내용은 API 책임이라고 확정했다. 따라서 이 실패를 Viewstem 결함이나 현재 미해결 보안 문제로 사용하지 않는다. 현재 계약·테스트는 [상위 실험](../../README.md)을 따른다. 관찰된 전달 동작은 같으며, 잘못 설정한 책임 범위와 테스트 기대값을 정정한 것이다.
