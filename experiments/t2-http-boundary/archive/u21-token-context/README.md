# U21의 토큰 추출 문맥 실패

2026-10-30 U21에서 auth.token이 /secrets/password에 접근해 빈 destination으로 추가 resolver 호출을 수행하고, 반환값을 로그인 토큰 대신 사용하는 P30 실패를 확인했다. 당시 소스와 Node 22/24의 45/46 결과를 보존한다.

U22에서 사용자가 Login 응답만 읽도록 수정하고 연속 검증을 재개하라고 요청했다. 현재 수정·검증 상태는 [상위 실험](../../README.md)을 따른다. 이 폴더는 수정 전 증거이며 현재 실행 소스로 사용하지 않는다.
