# U25의 headers 객체 참조 실패

2026-10-30 P51에서 headers 객체 전체의 @path를 정적 헤더 이름으로 검사해 정상 요청을 거절했다. 당시 소스와 Node 22/24 각각 145/146 결과, 같은 실행기의 88/88 Node/Chromium 전송 대조를 보존한다.

U26에서 사용자는 headers 전체 @path 지원과 금지 헤더 검사 유지, 문서 반영·연속 검증을 요청했다. 현재 상태는 [상위 실험](../../README.md)을 따른다. 이 폴더는 수정 전 증거다. 전송 결과의 ../t2-url-races 해시는 당시 상위 실험의 인접 폴더 기준이다.
