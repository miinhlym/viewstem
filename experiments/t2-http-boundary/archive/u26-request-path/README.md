# U26의 request.path 참조 실패

2026-10-30 P61에서 request.path 표현식을 평가하지 않고 문자열 URL 검사에 넘겨 정상 요청을 거절했다. 당시 소스와 Node 22/24 각각 226/227 결과, 같은 실행기의 122/122 Node/Chromium 전송 대조를 보존한다.

U27에서 사용자는 request.path 평가와 기존 주소/목적지 검증 유지, 문서 반영·연속 검증을 요청했다. 현재 상태는 [상위 실험](../../README.md)을 따른다. 이 폴더는 수정 전 증거다. 전송 결과의 ../t2-url-races 해시는 당시 상위 실험의 인접 폴더 기준이다.
