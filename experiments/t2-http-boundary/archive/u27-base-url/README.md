# U27의 baseUrl 참조 실패

2026-10-30 P71에서 Datasource.baseUrl 표현식을 평가하지 않아 정상 요청을 거절했다. 당시 소스와 Node 22/24 각각 260/261 결과, 같은 실행기의 146/146 Node/Chromium 전송 대조를 보존한다.

U28에서 사용자는 baseUrl 및 @path 관련 전체 구현을 검사하고 확정 계약 위반은 재질문 없이 해결하도록 요청했다. 현재 상태는 [상위 실험](../../README.md)을 따른다. 전송 결과의 ../t2-url-races 해시는 당시 상위 실험의 인접 폴더 기준이다.
