# U30 재개 정책 변경 전 증거

U31에서 autoRefreshWhen false→true의 즉시 fresh 갱신과 완료 기준 재예약을 확정하기 전 소스·결과다. U30의 마지막 완료 deadline 유지 동작은 당시 private 실험 선택이며 현재 계약이 아니다.

`snapshot/experiments/` 아래 polling·복합 Query·Query 경합·Query–HTTP의 Node 22/24 결과와 각 sourceSha256 대상 소스를 저장했다. 각 결과 파일의 실험 디렉터리를 기준으로 상대 경로 해시를 검증했다.

현재 계약·결과는 [현재 polling README](../../README.md)를 따른다.
