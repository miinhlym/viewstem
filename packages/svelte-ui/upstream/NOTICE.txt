This package includes Vega UI components and Tailwind utilities from shadcn-svelte.
Source: https://github.com/huntabyte/shadcn-svelte/tree/fe4b0ad3b8b30c6745346db008c3307b5afeabb1
The Viewstem generator rewrites import paths, selects Lucide icons, resolves
remaining default preset markers, and attaches style scope markers.
Deterministic local compatibility fixes compose internal/consumer handlers,
scope dynamic elements, suppress disabled anchor activation, react to carousel
orientation/options, and recheck changed avatar sources after automatic loading.
See scripts/vendor-source.mjs in the source repository for the complete transforms.
