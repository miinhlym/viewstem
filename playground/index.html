    실행 준비초안
    
  
    플레이그라운드 사용 안내
    
    
    예제를 불러온 뒤 JSON을 수정하고 실행을 누르세요. 실행할 때마다 State와 Query를 새로 시작합니다. 구성 오류가 나면 마지막 정상 화면을 유지합니다. 중지는 실행과 구독을 정리합니다.
    
    
    JSON 형식
    { "resources": [], "view": { "render": { … } }, "inputs": {} }
    resources에는 core 리소스를 등록합니다. view 대신 등록한 View의 viewRef도 사용할 수 있습니다. inputs는 선택 사항입니다.
    
    
    화면 컴포넌트
    
    
    상태 읽기
    State·Query·Action 패널은 View 최상위 상태를 보여줍니다. Action 관찰에는 이벤트 연결의 on.click.id 같은 관찰 ID가 필요합니다. Component 내부는 전체 snapshot에서 입력·수명·하위 화면을 확인할 수 있습니다.
    
    
    HTTP 예제
    로컬 /api/concepts는 검색과 응답 지연, 실패 재현을 제공합니다. 다른 주소를 입력하면 브라우저가 직접 요청하므로 해당 API의 CORS 정책을 따릅니다. 서버 프록시나 secret 저장소는 제공하지 않습니다.
